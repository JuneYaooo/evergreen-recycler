# 对标：回收排期工具与本项目定位（2026-09-19 调研）

调研方法：公开网页搜索与产品定价页/帮助文档阅读；引用版权归原作者所有，仅作定位说明。
各产品的规则细节以官方文档为准且随时可能调整，本仓库只借鉴其**公开的排期规则参数**。

## 需求证据

- HubSpot 官方博客分析：其 **76% 的月博客浏览量来自旧帖**（后续口径约 89%），
  **92% 的博客线索来自旧帖**——旧内容是流量的主要载体，"历史优化"因此成为正式策略。
- "常青回收"是被单独付费的能力：CoSchedule 从 $29/月入门档就内置 ReQueue；
  ContentStudio 的 Evergreen Automation 是核心付费功能（$19/月起）；
  SmarterQueue 直接以 evergreen 回收立身。
- 最高频差评是**贵**：G2/Capterra 上 CoSchedule、ContentStudio 的评论反复出现
  "too expensive / not affordable"；且两家都要求把社交账号 OAuth 授权绑定自家平台，
  CoSchedule 的 X 账号还要按 $16/账号/月另付。
- **对国内博主完全不可用**：小红书/抖音/公众号没有开放给这些海外工具的发布 API，
  必须绑定 OAuth 的自动化产品全部失效；国内创作者在手工做"删了重发/没流量再发一次"，
  恰恰是被平台判重复的高危动作。

## 现有方案与本项目的差异

| 方案 | 回收/排期做法 | 与本项目的差异 |
| --- | --- | --- |
| CoSchedule ReQueue（$29/月起，Starter 5 组） | 手动标记常青组，Intelligent 组填日历空档；同条消息两周内不重发；常青组 3 条/周起步，库大后 7-14 条/周 | 只在自家日历体系内工作、需 OAuth 绑定账号；**赢家靠手动标记**，不检测数据。本脚本：本地 CSV、自动赢家检测、同帖间隔 60 天更保守 |
| ContentStudio Evergreen（$19/月起） | 手动选 ≥2 条循环再发，支持 Cycle Gap 轮次间隔与文案 Variations | 仅社交帖、需订阅与授权；变体靠用户自己想。本脚本：Agent 按帖生成变体方向 |
| SmarterQueue | 分类队列循环 + 每帖过期条件；同文本 24h 内禁发、同条每周 ≤2 次；per-cycle 分轮数据对比 | 规则最完整但同样手动选帖、订阅制。本脚本的间隔/配额参数即参照其公开规则取保守值 |
| Postiz（开源，≈36k★） | 开源排期 SaaS，帖子可按周期重复 | 重复间隔上限仅 1 个月，需自部署 + 平台 OAuth；**无比对历史数据的赢家检测，无变体建议闭环** |
| social-auto-upload（开源，≈15.1k★） | 自动上传视频到抖音/小红书/视频号等 | 纯上传自动化：不回答"翻哪条、何时翻、怎么改" |
| Sheets/飞书发布台账 | 人工记录日期×平台×内容 | 无基线对比、防重复靠记忆；本脚本输出仍是 CSV/MD，可直接回流到现有表格 |

## 本项目的定位

- **输入是本地导出，不是平台授权**：博主从创作者后台手工导出台账即可运行，
  零订阅费、零 OAuth、零上传，正好落在海外付费工具的差评区（贵+绑定）与
  国内市场的空白区（无 API 可接）。
- **赢家检测是自动的，不是手动标记**：以账号自身平台内中位数倍数 + 分位数找赢家，
  每条建议附依据，可复核可调参；这是检索到的同类产品均未公开提供的能力。
- **输出是变体重发建议，不是自动发布**：平台对重复内容查重趋严（小红书 180 天
  内容指纹、抖音搬运判定），"生成变体 + 人工发布"比"自动重发"更安全，
  也因此不接管账号、不承担封号风险。
- 边界：不做大盘诊断、不做粉丝分析、不预测流量；平台规则漂移时需用户自行收紧参数。
